## WKWebView Lab

An independent iOS demo exploring the boundary between native Swift code and bundled web content.

- Request/reply messaging with payload validation and main-frame authorization.
- Controlled navigation and explicit WebKit lifecycle cleanup.
- Loading, failure, and web-process recovery states.
- Foundation policy tests and an iOS UI integration test.

Stack: Swift, SwiftUI, WebKit, JavaScript, XCTest.
